# Employee Leave Management System

A Flask-based Employee Leave Management System developed using Python, Flask, MySQL, HTML, CSS, and JavaScript.

## Features

- Employee Login
- Admin Dashboard
- Manager Dashboard
- Apply Leave
- Emergency Leave
- Leave Approval/Rejection
- Forgot Password System
- File Upload Support
- Role-Based Access

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
